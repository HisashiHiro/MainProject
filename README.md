# Веб-приложение "Заметки"

### Описание: 
Создать веб-приложение для управления заметками пользователей. Приложение должно позволять пользователям создавать, просматривать, обновлять и удалять заметки. Также можно добавить функционал для добавления тегов к заметкам или возможность установки срока давности для каждой заметки.

### Требования:
- Веб-интерфейс позволяет создавать, просматривать, обновлять и удалять заметки.
- Заметки сохраняются в базе данных, чтобы они были доступны между сессиями.
- Реализована аутентификация пользователей, чтобы каждый пользователь видел только свои заметки.
- Применение шаблонов HTML для отображения пользовательского интерфейса.
- Обработка ошибок и валидация пользовательского ввода, чтобы предотвратить некорректные данные.

### Развертывание
Развертывание сервиса должно осуществляться с использованием docker compose в директории с проектом.

### Хранилище данных (MongoDB) и история изменений (Redis)
- **Основные данные**: MongoDB (коллекции `notes`, `users`, `tags`, `sessions`, `counters`).
- **История изменений**: Redis. Каждое событие аудита записывается отдельным ключом `audit:event:<event_id>` с TTL, а также индексируется списком `audit:index:<entity_type>:<entity_id>`.
- **TTL на каждое событие** настраивается через `REDIS_AUDIT_TTL` (например `168h`).

### Запуск MongoDB + Redis
Из корня проекта:

```bash
docker compose up -d
```

### Запуск приложения
1) Убедитесь, что заполнен файл `cmd/NotesApp/.env` (JWT + параметры MongoDB/Redis).
2) Запустите HTTP API:

```bash
go run ./cmd/NotesApp
```

После запуска:
- HTTP API: `localhost:8080`
- Swagger: `localhost:8080/swagger/index.html`
